# Professional Portfolio (Client)

This is the frontend (Vite/React) for your professional portfolio.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploying to Vercel

1. **Push this `client` folder to GitHub.**
2. **On Vercel:**
   - Set **Root Directory** to `client`
   - Set **Build Command** to `npm run build`
   - Set **Output Directory** to `dist`
   - Set **Framework Preset** to Vite
3. **Deploy!**

All static files in `public/` (PDFs, images) will be served at the root of your deployed site.
